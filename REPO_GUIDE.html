gateway

PathPurpose
app/main.pyFastAPI app, startup, route mounts.
app/core/Settings (config.py), auth and permission dependencies, rate limiting, v1 deprecation.
app/routers/, app/routers/v2/Endpoints, registered in app/routers/__init__.py.
app/services/Business logic, MQTT callbacks, notifications, Slack.
app/schemas/, app/models/, app/repositories/Pydantic models, SQLAlchemy models, data access.
app/db/Session, model registry base.py, Alembic migrations/.
app/workers/Celery tasks.
app/test/Standalone test scripts.
relay/Radar live relay: frame assembly, clips, leader election, Node verdict CLI.
webhook_dispatcher.pyTenant webhook outbox daemon.
seed_tenant.py, wellness_populator.pyTest tenant seed, synthetic wellness data.
*.sh (root)Cron callers for aggregates, fall scheduler, health checks.
db_migration_scripts/, scripts/One-off legacy import, backfills and tools.

KuboCare-Socket

PathPurpose
index.jsEntry: Express, socket auth, tenant namespace, MQTT, ghost filter, Twilio audio.
socketServer.js, socketHandler.jssocket.io setup and CORS, room join handlers.
mqttClient.jsMQTT subscribe and topic switch to handlers.
handlers/One handler per data type (alerts, vitals, viz, ambience, bed, audio).
filters/Ghost filter for radar point clouds, with tests.
auth/, tenant/JWT and device access checks, tenant namespace and fan-out.
lib/, utils/Prisma singleton, ghost filter hydrate, emit helpers, Redis key ignore list.
prisma/Schema pulled from the gateway database.
docs/Data flow, tenant socket plan and FAQ, testing and load testing.
scripts/, scratch/Ambience simulator, ad-hoc dev scripts.

KuboCare-frontend-WEB

PathPurpose
app/expo-router file routes; [locale]/ holds all screens.
features/Self-contained modules: visualizer, room configurator (rrc), overview.
