Commands to sync branches, run, test and migrate the gateway, socket and frontend repos locally. Run from ~/Desktop/KuboCare/kubocare-stack.

Whole stack

bash scripts/setup.sh          # first time, idempotent: deps, redis container, migrations, clip dir
bash scripts/dev.sh up         # stop + redis + gateway/socket/web, one terminal window each
bash scripts/dev.sh health     # all three print 200
bash scripts/dev.sh stop       # teardown

setup.sh needs uv, Node, Docker, a running Postgres and the three .env files (copied by hand, never created by the script). Login, fall replay and troubleshooting steps are in kubocare-stack/CLAUDE.md.

Sync working branches with base

git -C gateway fetch origin && git -C gateway merge origin/dev-in
git -C KuboCare-Socket fetch origin && git -C KuboCare-Socket merge origin/dev-in
git -C KuboCare-frontend-WEB fetch origin && git -C KuboCare-frontend-WEB merge origin/dev-fastapi

Check you are on the working branch first: git -C <repo> branch --show-current.

gateway

cd gateway
uv sync
uv run fastapi dev
uv run celery -A celery_worker.celery worker --loglevel=info -P solo
  • Set your own MQTT_SHARE_GROUP in .env or local dev steals messages from the deployed gateway.
  • /docs only exists when APP_ENV=development.

Migrations

uv run -m alembic revision --autogenerate -m "short message"
uv run alembic upgrade head
uv run alembic heads

After a migration the socket reads, refresh Prisma there (see below).

Tests

set -a; source .env; set +a
.venv/bin/python -m app.test.test_out_event_slack

KuboCare-Socket

cd KuboCare-Socket
npm install
npx prisma generate
npm start
  • Port 5050 by default.
  • Tests: node auth/socketAuth.test.mjs, node filters/ghostFilter.test.mjs, node filters/vizRaw.test.mjs.
  • Prisma after a gateway migration: npx prisma db pull && npx prisma generate. Never run prisma migrate here.

KuboCare-frontend-WEB

cd KuboCare-frontend-WEB
npm install --legacy-peer-deps
npm run web
  • Checks: npm run lint, npx jest, npx tsc --noEmit.
  • Production build (what Amplify runs): npx expo export --platform web.
  • After changing the socket's ghost filter: npm run sync:ghost-filter.
