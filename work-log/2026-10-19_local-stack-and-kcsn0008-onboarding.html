Local run (safe mode)

  • Env files built from the DEV vault copies with local overrides marked # LOCAL OVERRIDE. Git-ignored, mode 600 for gateway and socket.
  • Local Redis (kubocare-redis): OTP, replay ring and the relay ingest lock stay off DEV Redis.
  • Gateway alert, SOS, button and ambience topics and the socket vitals topic point at local-hrishi/disabled/*, own share group local-hrishi. Twilio and Datadog keys blanked.
  • Relay: fall capture, auto-clip, verdict worker, local archive and blob storage off, so nothing writes clips or verdicts into DEV rows. EXTENDED_POST_FALL_ENABLED=true, INCIDENT_WINDOW_SEC=10.
  • FASTAPI_DEBUG=true so OTPs go to local Redis instead of Twilio (env only, no code toggle).
  • Finding: the DEV env pins INCIDENT_WINDOW_SEC=30, so deployed DEV stores and replays ±30 s, not the ±10 s code default.
