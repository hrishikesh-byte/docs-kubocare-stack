What changed

  • Merged the kit's repo guides into the gateway, socket and frontend CLAUDE.md files (relay and verdict rules, viz stream rules, visualiser replay rules, run gotchas).
  • New kubocare-stack/scripts/: setup.sh, dev.sh, ghost_filter_objs.py. dev.sh up now also opens ptyxis windows, the terminal on this laptop.
  • Tool repos switched to their working branches: test framework backend version2, test framework frontend workflows, IoT automation backend and frontend dev. Credential management stays on main by design.
  • Credential management got a local CLAUDE.md from the kit. The other four tool repos already have the kit's guide committed (AGENTS.md with a CLAUDE.md symlink), unchanged.
  • The kit's per-repo scripts were already in the tool repos, identical. Nothing copied.
