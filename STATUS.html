Known risks

Found while mapping the repos. None fixed yet.

  • gateway: a live cron API token is committed in the root cron shell scripts. It should be rotated and read from env.
  • frontend: providers/AuthProvider.tsx starts as logged in and auto-logs in as a demo admin. Dangerous if it reaches prod.
  • gateway: pyproject.toml says Python 3.13, the Dockerfile builds on 3.12. Docker installs from requirements.txt, not uv.lock.
  • socket: no lockfile (package-lock.json is git-ignored), so installs are not reproducible.
  • frontend: no feature flag system. Convention set in the agent guide: EXPO_PUBLIC_<FEATURE>_ENABLED, default off.
  • tests: no test runner in gateway or socket; tests are standalone scripts. No CI test step in any of the three repos.
